# DomiGo — 1st Grade Vocab Trainer

EFL vocabulary trainer for 1st-grade (1ABC) students at Gymnasium der Dominikanerinnen, based on **MORE! 1** (CEFR **A1**).

**Live:** https://veho-domi.github.io/1st-grade-vocab-trainer/

## What it does
Practice modes (Sprint, Speed, Multiple Choice, Flashcards, Full Run) and arcade mini-games (Memory Match, Word Hunt, Spelling Bee, Grammar Memory Match, Grammar Blitz, Error Hunt, Group Sort, Matching Pairs, Anagram). The *Lost Pages / Die verlorenen Seiten* story campaign offers a chat-sim narrative experience. Battle Arena and Class Quiz support live multiplayer.

## Tech
Single-file vanilla HTML/JS app (`index.html`, ~16.8K lines). Firebase (`veho-vocab` project) for student data and live battles. GitHub Pages for deployment. No build step.
